# Release 0.3.1 (2026-09-24) — iOS relay support, error text, centred Remove

Everything on `master` since 0.3.0 (`a54315f`), plus the two branches that
were waiting:

## 1. What changed

- **Relay (PR #2, #3):** the iOS app's origin `secure-chat://app` is on the
  WebSocket allow-list and in the `/api` CORS list, so the sideloaded iOS app
  can connect. The CSP gains `manifest-src 'self'` and `worker-src 'none'`,
  and `.webmanifest` is served as `application/manifest+json` (Home Screen web
  app). No wire-format, DB or systemd change.
- **Client (PR #3):** web-app manifest and icons, safe-area padding in
  landscape.
- **Client (`android-ondevice-2026-09-21`):** `formatDetail` — an error
  response is always one line of text; a FastAPI 422 no longer shows
  `[object Object]`. This fix was served from 2026-09-22 until the 0.2.0
  deploy replaced it; it is back now. Plus the Android on-device notes.
- **Client (`fix/contact-remove-row`, profile round 7):** the lone Remove (and
  the lone Unverify) in the contact profile sits centred.
- `backend/config.py` `VERSION = "0.3.1"`; Android `versionCode 4`,
  `versionName 0.3.1`.

Not part of this deploy: the Caddyfile's `/ios/` download block — it only makes
sense once an IPA is published (`deploy/README.md`, "iOS app downloads").

## 2. How it was checked

Each branch was reviewed on its own (formatDetail: pentest pass, 2 Low + 1
Info fixed in `dfadca9`; round 7: design critic + pentest pass 7, nothing above
Low). On the merged tree: relay suite (170), client unit tests, and the six
e2e runs (`contact-profile`, `no-dead-ends`, `room-admission`,
`two-user-flow`, `hostile-relay`, `all-modes`) against a local relay.

## 3. Deploy

```bash
# from a checkout of v0.3.1 (local master has diverged: use a detached checkout)
git fetch origin && git checkout --detach v0.3.1
bash deploy/deploy-2026-09-24-v0.3.1.sh
```

The script refuses a checkout that is not 0.3.1, backs up the DB with the
service stopped, and verifies on the box: `/healthz` 0.3.1, the served client
carries the manifest, `formatDetail` and the centred Remove row, the manifest's
content type, `worker-src 'none'`, a CORS preflight from the iOS origin
allowed and one from a foreign origin refused, the import map line, accounts
count unchanged, `SECURE_CHAT_TRUSTED_PROXIES` unset, loopback only.

Rollback: `git checkout v0.3.0 -- client backend` and the rsync + restart
steps of the script; the DB is untouched.
