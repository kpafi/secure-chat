# Release 0.2.0 (2026-09-23) — the design rework

Ten commits on `claude/secure-chat-design-rework-rxd4uz`, merged `--no-ff` into
`master`. What changed, how it was checked, how to deploy, and what to look at
on a device.

## 1. What changed

Only the web client and the version string. No crypto, no wire format, no
relay behaviour, no DB change.

- `client/style.css` rewritten as a system (tokens, a six-size type scale, a
  4/8 px rhythm, a surface ladder with hairlines, one accent with one job),
  `client/index.html` restructured (persistent tab bar / top bar instead of
  the drawer, a first-run welcome, "?" disclosures for explanations, collapsed
  optional rows), `client/app.js` changed in named places only (navigation
  binding, no emoji in status strings, guidance strings shortened, an
  admission guard, a modal admission sheet with focus restore, the trust pill
  and "verified" state, keyboard chat rows, relay error mapping, refusals
  that survive the close, socket-tied message handling, four pre-existing
  feedback bugs).
- `backend/config.py` `VERSION = "0.2.0"`; `android` `versionCode 2`,
  `versionName 0.2.0` — the APK bundles the client, so it needs a rebuild to
  show the new design, but the old APK keeps working against the new relay.

The design decisions and every review are in `design/` — start with
`design/README.md`, then `design/research/reviews.md`.

## 2. How it was checked

Per commit: client unit tests, backend pytest (162), the five e2e runs
(`two-user-flow` 14, `room-admission` 46, `no-dead-ends` 17, `hostile-relay`
24, `all-modes` 32 — up from 8 / 13 / 16 / 11 / 32; each new behaviour has
a check that its own mutant fails), `e2e/screenshots.mjs` (20 states at
phone and desktop size, no overflow), a design critic and a correctness /
accessibility critic in rounds until no blocker or major remained, and a
pentest of each diff (`.claude/agents/pentest-new-code.md`), in total nine
passes: nothing Critical / High / Medium; seven Lows found and each fixed
with a test (phone-layout tap-through on the admission sheet, refusal text
under the tab bar, a prompt armed while the page was hidden, two more
refusals erased on close, a relay-parked reason relabelling a client close,
"Leave chat" over the composer, frames processed after `onclose`); one
pre-existing Low fixed (a stale key-changed sentence on the verify gate).

## 3. Deploy

```bash
# on your machine, from the repo root
git checkout master && git pull
bash deploy/deploy-2026-09-23.sh        # backup, rsync, restart, verify (needs ssh to the box)
```

The script refuses to run on a checkout that is not 0.2.0. It verifies on the
box that `/healthz` reports `0.2.0`, that the served `index.html` carries the
tab bar, `app.js` the admission guard and `style.css` the new tokens, that the
import map line is still there (its CSP hash is unchanged — the line is
byte-identical), that the accounts count did not change, and that
`SECURE_CHAT_TRUSTED_PROXIES` is still unset.

Rollback, if ever: `git checkout 3e55bff -- client backend/config.py` and run
the 2026-09-21 script's rsync + restart steps; the DB is untouched by 0.2.0.

## 4. Android

```bash
git checkout master && git pull
(cd android && ./gradlew assembleRelease)      # or assembleDebug for the test phone
adb install -r android/app/build/outputs/apk/release/app-release.apk
```

Then on the phone, in this order: the first screen is the identity step with
the bottom tab bar; unlock; Chats → a conversation → the tab bar disappears
inside it and the composer stays above the keyboard (rotate to landscape:
a compact icon-only bar); Live room → Connect → let a second device knock:
the sheet must sit above the tab bar, focus lands on Deny, a tap in the first
half second decides nothing; verify → "connected" turns neutral and a green
"verified" pill appears. In Windows high-contrast / Android "high contrast
text" the shield icons and the current tab must still show.

## 5. Known and deferred

  were emulated). Safari and a physical Android device have not been looked
  at; do that once after the deploy.
- The stylesheet is 21 KB gzip (was 6 KB).
- Deferred behaviour changes are listed under "Phase 2" in
  `design/research/reviews.md`.
