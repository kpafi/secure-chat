How to hand a pad over

Export the encrypted file and give it to your contact in person (Bluetooth, USB, QR…); they import it. A pad is a shared secret for exactly two devices — never import it on more than one.

Drawing in the box folds your own physical randomness into the pad. It is optional: the OS random generator is used regardless.

Import on one device only — never the same pad twice.

Why only one device?

A pad may be imported on only ONE device per side. Importing the same file on more than one device causes catastrophic key reuse — generate a separate pad for each contact.

The transfer passphrase protects the file: agree on it in person, and make it different from your pad passphrase.
